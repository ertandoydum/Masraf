# Masraflarım

Kişisel aylık masraf ve iade takip uygulaması (iPhone için).

**Kullanım:** https://ertandoydum.github.io/masraf/ adresini iPhone'da Safari ile açın → Paylaş → **Ana Ekrana Ekle**.

- Kayıtlar yalnızca kullanan kişinin telefonunda saklanır; internete veya bu depoya gönderilmez.
- Bu depoda sadece programın kodu bulunur.
- Yedek: Ayarlar → Yedek al (iCloud Drive'a kaydedilebilir) / Yedekten yükle.
